# Changelog

## 0.1.0 — 2026-11-08

- Initial beta: recursive folder visual search, single-video visual retrieval, local screenshot OCR and speech transcript search.
- Simplified UI with three search modes and internal threshold selection.
- Added Simplified Chinese and English interface selection with a saved browser preference.
- Chinese speech script normalization and supported integer-with-unit matching.
- Clip estimated speech ranges to decoded audio duration and discard empty ranges; version speech caches to invalidate old out-of-bounds results.
- English/Chinese setup, small fictional examples, evaluation scope and Windows CI configuration.

Known limitations and validation scope are documented in the READMEs and docs directory.
